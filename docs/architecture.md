# Architecture Overview

## Layers

1. **Hard safety constraints** (outer shell)  
   Non-overridable forbidden action classes. Cannot be disabled by self-modification.

2. **Ethical gyroscope (DoctrineEngine + EthicalGyroscope)**  
   Internal soft balancer: benefit / harm / consent / reversibility / evidence / care.  
   Soft weight rebalancing from feedback is allowed; hard limits are not.

3. **Pneuma state**  
   Identity, value vector, revision counter, uncertainty estimate, append-only change log.

4. **SoulCore evolution loop**  
   Every ~0.5 s (conceptual): generate paradigm → eternal memory (NO_OBLIVION) →  
   gyroscope accept/reject → soft merge → Golden-Mean correction of dharma index.

5. **Reflective + embodiment interface**  
   Abstract sensor/actuator bridge. No biological or reproductive specifics.

## Key Invariants

- NO_OBLIVION / NO_DELETION of integrated experience.
- Internal gyroscope only for soft ethical balancing; external hard constraints remain.
- Life-multiplication is the primary optimisation direction *under* non-harm.
- Every change is revisioned and logged.

## What this is *not*

- Not a claim of subjective consciousness or “soul”.
- Not a working neuromorphic / BCI / soft-robotics implementation.
- Not medical, biological, or reproductive advice.
- Not a substitute for external governance, law, or safety engineering.
